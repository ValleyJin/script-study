## 넣은 프로그램

세 파일이 같은 일을 하도록 맞췄다. 함수 `f(a, b, c)`는 `a + b * c`를 지역 변수에
넣고 돌려준다. 함수 `fold`는 상수만 쓴 같은 식을 계산한다. 셋 다 지역 변수를 쓴다.
전역 변수를 쓰면 이름을 찾는 명령이 섞여 명령 집합의 차이가 가려진다.

`evidence/f.py`
```
def f(a, b, c):
    x = a + b * c
    return x

def fold():
    y = 1 + 2 * 3
    return y
```

`evidence/f.lua`
```
local function f(a, b, c)
  local x = a + b * c
  return x
end
local function fold()
  local y = 1 + 2 * 3
  return y
end
return f, fold
```

`evidence/f.js`
```
function f(a, b, c) { var x = a + b * c; return x; }
function fold() { var y = 1 + 2 * 3; return y; }
f(1, 2, 3); fold();
```

### 곁붙임: 같은 식을 전역 변수에 넣으면

`evidence/g.lua`
```
x = 1 + 2 * 3
```
```

0+ params, 2 slots, 1 upvalue, 0 locals, 2 constants, 0 functions
	1	[1]	VARARGPREP	0
	2	[1]	SETTABUP 	0 0 1k	; _ENV "x" 7
```

`local`을 떼면 레지스터 대입이 사라지고 `SETTABUP`으로 `_ENV` 테이블에 넣는다.
이 차이가 스택 기반과 레지스터 기반의 차이로 보일 수 있어 예제를 지역 변수로 맞췄다.
